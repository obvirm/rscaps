2. KEPUTUSAN USER (dari question tool — SUDAH FINAL, jangan ditanya ulang)
================================================================---------------
1. Template engine = "Opsi 2 langsung": Rust + param JSON + RUNTIME SVG template
   parser + mini bahasa ekspresi ({lerp(a,b,wordProgress)}, progress, dst) sebagai
   escape hatch setara tab CSS tscaps, DARI HARI PERTAMA (bukan fase 2).
   Konsekuensi: animasi digerakkan frame.animate(timeline!(...)) / ekspresi per frame,
   bukan @keyframes; perlu cache runtime (hash source -> SVG/evaluator); ikut API Svgr.
2. Scope fase 1 = SEMUA fitur tscaps: transkripsi otomatis, import subtitle +
   burn-in + preview, galeri template, editor penuh (timeline + per-element).
3. Porting 44 template tscaps (SCSS+keyframes -> Rust/SVG): SEMUA sejak awal.
4. UI studio = React custom (Vite + React + TS) — user sempat ragu mau "Rust total",
   tapi disepakati: view tetap React; Rust hanya utk logika. (Alasan: fframes saja
   menulis editornya pakai React/ReScript; timeline editor UI paling sulit.)
5. Transkripsi = ONNX Runtime (crate `ort`) wasm dari Rust, model Whisper ONNX.
   FALLBACK jika spike gagal: transformers.js + onnxruntime-web (pola tscaps MIT).
6. Export = lapisan TS tipis: Rust menghasilkan string SVG per frame -> rasterisasi
   <img>+canvas (paritas dengan preview karena sama-sama Blink) -> VideoFrame ->
   WebCodecs VideoEncoder -> mux MP4 via mediabunny. Audio: remux/decode dari source.
   (Alternatif "resvg-wasm di Rust" DITOLAK karena bisa beda hasil render dari preview.)
7. Keputusan arsitektur preview: BACKGROUND VIDEO TIDAK digambar fframes.
   preview = <video> HTML + overlay SVG caption transparan di atasnya;
   export  = drawImage(decoded VideoFrame) + overlay SVG caption di atasnya.
   => SVG caption selalu mandiri/tanpa href eksternal -> rasterisasi <img> aman.
   __fframes_get_video_frame baru dibutuhkan untuk efek yang sampling piksel video
   (blur/backdrop) — fase lanjutan.
8. Referensi produk lain yang DITOLAK user: subtitler (dmtrKovalenko) — "sudah mati
   dua tahun", beda jauh dari tscaps.

  ditambahkan saat stylesheet disusun; @keyframes milik elemen itu; animasi wajib
  pakai var(--timing) sebagai delay).
- Jadi tscaps TIDAK punya tab script JS / HTML. Escape hatch-nya = CSS (+ filters.svg).
- PRODUK KITA: tab sama (templates, transcript, typography, style, position, motion,
  effects, layout, code), tapi tab 'code' berisi SUMBER TEMPLATE kita
  (SVG + ekspresi mini) menggantikan CSS, karena engine kita SVG/Rust bukan DOM/CSS.
  Editor memakai CodeMirror (@uiw/react-codemirror) persis pola CodeEditorField
  (debounce 250ms, validator sync, dialog maximize, height 60vh).
